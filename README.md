# Sales Performance Dashboard – Task 4

## Project Overview
This project focuses on designing an interactive sales dashboard for business stakeholders using Tableau Public.

## Objective
To create a dashboard that provides a clear overview of sales performance, profit, quantity, trends, categories, regions, and top-performing products.

## Tools Used
- Tableau Public
- CSV Dataset

## Dashboard Features
- Total Sales KPI
- Total Profit KPI
- Total Quantity KPI
- Average Profit Margin
- Monthly Sales Trend
- Sales by Category
- Sales by Region
- Top 10 Products
- Interactive filters for Region, Category, and Order Date

## Dataset
The dataset contains 500 sales records with information about orders, dates, regions, states, products, customers, quantity, sales, and profit.

## Key Insights
The dashboard helps stakeholders identify sales trends, profitable categories, high-performing regions, and top products.

## Conclusion
The interactive dashboard provides a simple and effective way to analyze sales performance and support business decision-making.
